Adding "Comments" Feature

To master stack, build feature End-to-End (E2E). Example: "Comments" on a post.

Step 1: DB (packages/db)

// schema.ts
export const comments = pgTable("comment", {
  id: serial("id").primaryKey(),
  postId: integer("post_id").notNull(),
  content: text("content").notNull(),
});

Step 2: API (packages/api)

// router/post.ts
addComment: publicProcedure
  .input(z.object({ postId: z.number(), content: z.string() }))
  .mutation(async ({ ctx, input }) => {
    return ctx.db.insert(comments).values(input);
  })

Step 3: UI (apps/web)

// PostView.tsx
const mutation = trpc.post.addComment.useMutation();

<Button onClick={() => mutation.mutate({ postId: 1, content: "Nice!" })}>
  Comment
</Button>

Your Task

Notice how type flows from DB -> API -> UI. If you change content to text in DB, UI will show type error.
