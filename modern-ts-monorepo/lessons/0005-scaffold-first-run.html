Lesson 5: First Run

Good choice. Scaffold saves hours. Focus on code, not config.

Run Scaffold

Open terminal in workspace.

bun create t3-turbo my-new-app

Follow CLI prompts. Choose Bun. Let it install.

Start Dev Server

Go to folder. Run dev.

cd my-new-app
bun dev

Turbo starts web, native, and server all at once. Cache magic active.
