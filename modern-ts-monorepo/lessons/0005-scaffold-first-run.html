Lesson 5

Running the Scaffolded App

Initialize and start the development environment in your workspace.

Good choice! Selecting the scaffold path saves hours of setup configuration and lets you focus on coding and understanding the architecture.

1. Generate the Codebase

Run the creation command in your terminal inside your project directory:

bun create t3-turbo my-new-app

Select Bun when prompted for the package manager. Wait for the dependency installation to finish.

2. Run the Development Server

Navigate to the newly generated project directory and boot up the development server:

cd my-new-app
bun dev

Turborepo will automatically launch the Next.js web application, Expo dev client, and Hono server concurrently in hot-reload mode.

Your Lesson Tasks

Generate a scaffolded workspace. Examine the root-level directories to ensure they align with our project design map. Take note of how scripts inside package.json trigger downstream scripts in the sub-directories.
