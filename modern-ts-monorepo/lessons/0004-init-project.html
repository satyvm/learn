Start From Scratch

Architecture clear. Now we build.

Building Turbo monorepo from zero hard. Too much config (TS, Biome, apps). Use scaffold tool instead.

Create-T3-Turbo

Best starting point: create-t3-turbo. Generates React/Expo/tRPC/Drizzle monorepo instantly. Very close to target stack.

bun create t3-turbo my-app

Alternatively: Build Manual (Hard Mode)

  1. bun init
  2. bun install turbo --dev
  3. Add turbo.json.
  4. Create apps/ and packages/.
  5. Configure package.json workspaces.
