Starting a Project from Scratch

Setting up a Turborepo monorepo manually is highly configuration-intensive. You must configure individual TypeScript configs (tsconfig.json) in all directories, manage peer dependency version alignment, set up package-manager workspaces, and configure Turborepo pipelines.

To avoid config fatigue, we recommend using a scaffolding script.

The create-t3-turbo Tool

The T3 community provides an official starter boilerplate named create-t3-turbo. This scaffold initializes a monorepo configured with Turborepo, Bun workspaces, Expo React Native, a Next.js (or React) frontend, Drizzle ORM, tRPC, Tailwind, and database configuration templates.

bun create t3-turbo my-app

The Alternative: Manual Configuration (Hard Mode)

If you choose to do a manual configuration:

  1. Initialize the repository: bun init
  2. Install Turbo: bun install turbo --dev
  3. Create and write a turbo.json configuration file.
  4. Establish directories for apps/ and packages/.
  5. Define workspaces inside the root-level package.json.
