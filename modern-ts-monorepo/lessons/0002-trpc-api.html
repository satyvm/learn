Step 2: API Layer

What is tRPC?

TypeScript Remote Procedure Call. No REST endpoints. No GraphQL schemas. Just export TS function from server, import type on client.

How it works

  1. Write router (server): getUser: publicProcedure.query(() => db.query.users.findMany())
  2. Export AppRouter type.
  3. Use on client (React): const { data } = trpc.getUser.useQuery()

If rename getUser to fetchUser on server -> Client build fails instantly. Type safety E2E.
