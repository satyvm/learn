Lesson 1: Monorepo Intro

Welcome. We build modern TS app. First step: Understand Monorepo structure.

What is Monorepo?

One git repo -> Many apps (Web, Mobile) + Many packages (DB, API). Code share easy. Types share easy.

Why Turborepo?

Monorepo slow without cache. Turbo cache tasks (build, lint, test). If file not change -> skip task -> fast.
