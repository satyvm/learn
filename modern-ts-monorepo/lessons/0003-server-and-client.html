Step 3: Server (Hono)

tRPC needs HTTP server to listen. apps/server uses Hono.

Hono is fast, runs anywhere (Node, Bun, Cloudflare). We mount tRPC on Hono route: app.use('/trpc/*', trpcServer(...))

Step 4: Client (Web/Native)

Now UI time. apps/web (React + TanStack Router) or apps/native (Expo).

Client imports AppRouter type from packages/api. No runtime code imported, just types!
