Step 3: The API Server (Hono)

We write our API routers, but they still need to be served over HTTP. This is where Hono (located in apps/server) comes in.

Hono is a ultra-fast, lightweight routing framework that compiles to work on any JS runtime (Node, Bun, Cloudflare Workers, etc.). We mount our tRPC API handler to Hono. Hono handles standard HTTP/REST requests (like auth webhooks) while letting tRPC manage the main E2E type-safe API requests.

Step 4: The Frontend Clients (Web/Native)

The client side of the application exists in apps/web (built with React + TanStack Router) and apps/native (built with React Native + Expo).

Both applications instantiate a tRPC client that imports the `AppRouter` type definition from `packages/api`. Because it imports only the type declarations, the bundle sizes of your web/mobile apps are unaffected by backend implementation code.

Once imported, you build components that query state directly from the backend, styled and arranged using Tailwind CSS and shadcn/ui.
