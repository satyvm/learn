# Mission: Master Modern TS Monorepo (T3/Turborepo)

**Goal:** Understand, learn, and build full-stack TypeScript apps from scratch using a modern Turborepo stack.
**Stack:** TS, TanStack Router, React Native/Expo, Tailwind, shadcn/ui, Hono, tRPC, Bun, Drizzle, Postgres, Better-Auth, Biome, Husky, Tauri.

**Why:** To build robust, type-safe web, mobile, and desktop apps sharing business logic and UI components efficiently.

**Target Outcomes:**
- Map features to monorepo structure (web/native/server apps + api/auth/db packages).
- Master end-to-end type safety with tRPC + Hono + Drizzle.
- Set up a project from scratch and confidently develop cross-platform features.
