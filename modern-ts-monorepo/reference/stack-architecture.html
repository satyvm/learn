Stack architecture

Type-safe systems across web, mobile, server, and shared packages.

Workspace map

apps/
  web        browser composition and interaction
  native     mobile composition and interaction
  server     HTTP runtime and adapters
packages/
  api        validated, authorized use cases
  auth       identity and session capabilities
  db         schema, migrations, persistence queries
  ui         intentionally portable visual components

Dependency rules

RuleReason
Apps may import packages; packages never import appsKeeps capabilities reusable and deployables compositional
Import through public package exportsPrevents consumers from depending on internals
No circular package edgesPreserves build order and conceptual ownership
Public API results, not raw rows, reach clientsDecouples interface contracts from persistence

Feature path

invariant → schema/migration → query → procedure
→ server tests → client mutation/query → visible states → behavior test
