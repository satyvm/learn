Stack Architecture Reference

Tech Stack "Why"

  • Turborepo: Fast monorepo build tool. Cache task runs. Manage dependencies between apps/packages.
  • TypeScript + tRPC: E2E type safety. API changes break build -> catch bugs early.
  • Bun: Fast JS runtime. Replace Node/npm/yarn. Speed up install/dev.
  • Hono: Edge-ready server framework. Tiny, fast. Perfect for tRPC endpoints.
  • Drizzle + Postgres: TS-first ORM. Type-safe SQL. Migrate easy.
  • Better-Auth: Drop-in auth. Type-safe session management.
  • TanStack Router: File-based routing for React. Type-safe links/params.
  • React Native + Expo: Mobile app. Share React logic with Web.
  • Tauri: Desktop app. Lightweight webview, Rust backend.
  • Tailwind + shadcn/ui: Rapid UI. Copy-paste components. Accessible.
  • Biome + Husky: Fast lint/format (replace Prettier/ESLint). Pre-commit hooks guarantee clean code.

Missing Pieces?

Stack very complete. Might need:

  • Hosting/Deployment: Vercel/Cloudflare for Web. Railway/Fly.io for DB/Server. EAS for Expo.
  • State Management: Zustand or Jotai (if complex client state needed outside server cache). TanStack Query (built into tRPC).
  • CI/CD: GitHub Actions to run Biome, tests, and Turbo build on PR.

Project Structure Mapping

project-x/
├── apps/
│   ├── web/     -> Browser UI (React). Fetches data via tRPC.
│   ├── native/  -> Mobile UI (Expo). Fetches data via tRPC.
│   └── server/  -> Hono API. Exposes tRPC router. Connects to DB.
├── packages/
│   ├── api/     -> tRPC routers, controllers. Imports from `db` and `auth`.
│   ├── auth/    -> Better-Auth config.
│   └── db/      -> Drizzle schema, migrations, DB connection.

Feature Dev Process

  1. DB (packages/db): Add table schema in Drizzle. Generate migration. Push to Postgres.
  2. API (packages/api): Add tRPC route (e.g., createPost). Import DB schema. Write logic.
  3. Server (apps/server): Mount new router (usually auto if setup right).
  4. Web/Native (apps/web): Use tRPC client (e.g., trpc.post.createPost.useMutation()). Build UI with shadcn/ui.
