Modern TypeScript Monorepo field guide

Type-safe systems across web, mobile, server, and shared packages.

Dependency direction

apps/* → packages/api → packages/db
                 ↘ packages/auth
apps/* → packages/ui
No package imports an app. No circular package edges.

Vertical slice checklist

LayerOwnsProof
DatabasePersistence constraints and queriesMigration + repository test
APIValidation, authorization, public resultBoundary tests
ClientInteraction and visible statesBehavior test
Share public contracts, not accidental implementation shapes. Keep task inputs explicit so caches remain sound.
