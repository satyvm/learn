01 / Mental model

Build the right picture first

Normal mode is a command language. Operators state an action, motions or text objects state a range, and counts repeat. Escape returns you to the grammar.

Modes change meaning

Use Insert for text entry, Normal for structure, Visual for an explicit selection, and Command-line for Ex commands and search.

Operator plus motion

d deletes, c changes, y yanks; w, $, }, and searches provide ranges. dw and c$ are compositional sentences.

Prefer intent-sized commands

A structured command is repeatable with dot and leaves useful history. Random movement plus backspace is harder to repeat.

02 / Worked example

Read commands aloud

ANNOTATED EXAMPLEread → predict → explain
ciw  = change inside word
da(  = delete around parentheses
y2j  = yank this line and two lines downward
3w   = move three word starts
.    = repeat the last change
The same objects work with different operators. Learn the grammar’s small vocabulary, then combine it.
03 / Deliberate practice

Do the work

Predict the result before each step. Keep a small note of what surprised you; surprise is useful evidence that your mental model changed.

  1. Run :Tutor and finish the opening sections.
  2. Change five words with ciw.
  3. Delete inside quotes and around quotes; observe the difference.
  4. Return to Normal mode after every insertion.
04 / Retrieval

Close the notes

What does d2w express?
Reveal answer

Delete over a motion of two words: operator d applied to count 2 and motion w.
