01 / Mental model

Build the right picture first

Neovim is an LSP client. A language server analyzes a workspace and answers standardized requests. Treesitter parses syntax locally for structural highlighting and queries; the systems complement rather than replace each other.

Attachment is per buffer

A configured server may fail to attach when root detection, filetype, executable, or project configuration is wrong. Inspect :checkhealth and :LspInfo.

Capabilities are negotiated

Definitions, references, rename, code actions, and formatting exist only when both client and server support them.

Diagnostics are locations

Severity, source, code, message, and position can populate loclist or quickfix for systematic repair.

04 / Retrieval

Close the notes

What is the difference between Treesitter and LSP?
Reveal answer

Treesitter parses local syntax; an LSP server provides project-aware semantic services over a protocol, such as definitions, references, and diagnostics.
