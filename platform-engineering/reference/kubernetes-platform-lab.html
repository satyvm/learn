Kubernetes platform lab

Build an internal platform as a product, from golden path to reliable operations.

Lab contract

Build a disposable local platform and keep an evidence journal. For every phase record the command or manifest, your prediction, observed state, one induced failure, diagnosis, repair, and cleanup proof.

Use a disposable cluster. Never run destructive drills against a shared or production context. Confirm kubectl config current-context before every phase.

Diagnostic order

kubectl config current-context
kubectl get <resource> -A -o wide
kubectl describe <resource>
kubectl get events --sort-by=.lastTimestamp
kubectl logs <pod> --previous
kubectl get endpointslices
kubectl auth can-i <verb> <resource> --as=<identity>

Graduation evidence

  1. Recreate the platform from versioned declarations.
  2. Explain a request path from DNS through Service to a ready Pod.
  3. Diagnose three injected failures without a runbook.
  4. Restore desired state after drift.
  5. Remove the cluster and verify no local or cloud resources remain.
