Session 08 · Verification

Prove boundaries before AWS

Most dangerous logic can be tested without renting a machine.

By the endCreate a risk-mapped test suite covering transitions, tenancy, idempotency, redaction, orchestration crashes, Compose validation, and Pulumi preview policy.
01 / Mental model

Tests buy evidence at different prices

Pure tests prove domain policy cheaply. Database/API integration tests prove boundaries. Static Compose/preview policy catches exposure and replacement. A small real canary proves provider and network reality. Use the cheapest layer capable of falsifying the claim.

Test invariants, not implementation

Assert legal transitions, ownership, stable outputs, and persisted effects rather than private function order.

Inject boundary failures

Timeout, partial success, duplicate delivery, malformed output, and process death reveal recovery design.

Cleanup is a test

A create path that passes while leaving volumes, addresses, stacks, or secrets is operationally failing.

03 / Deliberate practice

Your 60-minute session

  1. 0–12: Read the installed runner's official docs and Hono testing guide. Inventory current tests and commands; choose one canonical project test command and document it.
  2. 12–25: Build a risk register for at least ten failures. Assign each the cheapest adequate test layer and a clear assertion.
  3. 25–45: Add the highest-risk missing tests until the first seven claims above have executable evidence. Write helpers only after duplication appears.
  4. 45–54: Intentionally break one invariant, one authorization predicate, and one redaction rule. Confirm each test fails for the expected reason, then restore.
  5. 54–60: Run the full local suite and checks. Record duration, flaky behavior, and which claims still require AWS.
04 / Retrieval

Close the test files

What is the most dangerous untested crash window in this system?
Reveal answer

A side effect succeeds in AWS or on the host but the process dies before recording the verified result, because a naive retry can duplicate or corrupt resources.
