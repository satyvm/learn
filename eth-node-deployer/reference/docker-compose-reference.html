Compose runtime checklist

A secure self-service control plane from API request to healthy node.

Service graph

Lighthouse ── Engine API + JWT ── Nethermind
    │                                  │
    └──── metrics ─▶ Prometheus ◀──────┘
                           │
                        Grafana
Public ─▶ Caddy ─▶ explicitly allowed routes

Configuration review

AreaCheck
ImagesPin immutable versions; record upgrade notes
SecretsMount JWT and credentials with narrow permissions; never log
NetworksKeep Engine API, metrics, and admin ports private
StorageUse explicit persistent volumes and tested ownership
HealthProbe RPC response, peers, sync progress, and dependency readiness
ShutdownAllow graceful client stop before infrastructure teardown

Verification commands

docker compose config
docker compose pull
docker compose up -d
docker compose ps
docker compose logs --since=10m <service>
