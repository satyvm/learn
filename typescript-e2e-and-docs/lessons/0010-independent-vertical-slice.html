01 / Mental model

Slice by observable behavior

A vertical slice is the smallest user-visible behavior crossing the necessary layers. For this phase, success is local: a signed-in user submits or views a deployment draft and another user cannot see it.

Route owns navigation

TanStack Router maps file structure, auth layout, parameters, and loading/error boundaries to a URL.

Query owns server state

TanStack Query/tRPC cache remote results; local React state should not duplicate server truth.

UI renders all states

Loading, empty, success, invalid input, forbidden, and unexpected failure are part of the feature—not polish for later.

02 / Worked example

Define the acceptance path

BEHAVIOR, NOT IMPLEMENTATIONarrange → act → observe
Given an approved signed-in user
When they submit a valid deployment draft
Then the UI shows the saved public fields
And a reload still shows the record

Given a different signed-in user
When they visit the same deployment URL
Then no private deployment data is revealed

Given invalid input
Then the relevant field receives a useful message
Use the existing _auth route, shadcn primitives, and tRPC query options as evidence. Read only the Router/Query/Form documentation required by your chosen UI.
03 / Deliberate practice

Your 60-minute session

  1. 0–10: Retrieve the full request path from memory. Read TanStack Router file routing and inspect the current authenticated dashboard route. Write the route filename you expect to create or change and predict its URL.
  2. 10–20: Turn the three behaviors above into a short checklist. Sketch loading, empty, form, success, and failure states. Decide which state belongs in URL, server cache, or local form.
  3. 20–45: Author the smallest screen and client calls that satisfy the checklist. Use existing UI primitives; do not redesign the app. Follow inferred types instead of duplicating API interfaces.
  4. 45–55: Run the app and manually exercise valid, invalid, reload, logged-out, and second-user paths. Add the highest-value automated test exposed by a failure or risky seam.
  5. 55–60: Run all checks. In your own words, explain one file per layer and one trust boundary. Commit the coherent slice.
04 / Retrieval

Phase-one gate

What evidence is required before you treat this vertical slice as complete?
Reveal answer

Passing static checks/tests, observable valid and invalid behavior, persistence across reload, tenant isolation, no leaked internal fields, and your ability to explain each boundary without relying on copied code.
