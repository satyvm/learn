Jujutsu VCS (`jj`) field guide

A safer change-centric workflow on top of Git repositories.

Identity map

SymbolMeaning
@Working-copy commit
@-Parent of working copy
Change IDStable identity across rewrites
Commit IDExact immutable commit version
main@originRemote-tracking bookmark

Daily loop

jj status → jj describe → edit → jj diff → jj new
repair: jj edit OR child fix + jj squash
inspect: jj log / jj show / jj diff
recover: jj op log / jj undo / jj op restore

Revset starters

trunk()..@        open work relative to trunk
trunk()::@        paths from trunk through working copy
mine() & mutable() your rewritable work
conflicts()       commits containing conflicts
